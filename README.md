
# PocketTracker

A simple iPhone app for tracking personal expenses, built with SwiftUI.

> 🚧 Work in progress 

## Features
- [ ] Add an expense (title, amount, date, category)
- [ ] View a list of expenses
- [ ] See totals per category
- [ ] Save data between app launches

## Tech
- Swift / SwiftUI
- Swift Testing for unit tests
- iOS 17.6+, iPhone only

## Getting started
1. Clone the repo:
   `git clone https://github.com/jschuerch/PocketTracker.git`
2. Open `PocketTracker.xcodeproj` in Xcode.
3. Select an iPhone simulator and press **⌘R** to run, or **⌘U** to run the tests.

## Project structure
- `PocketTracker/Models` – data types (e.g. `Expense`)
- `PocketTracker/Views` – SwiftUI screens
- `PocketTrackerTests` – unit tests
